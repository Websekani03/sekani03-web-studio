My Coding Learning Routine (While Working as a Nurse)

These are my daily routines:

Days on Duty (Morning Shift)

  • Wake up at 5:30am, prepare and go to work
  • Work until 5:00pm and return home around 6:00-6:30pm
  • Rest, eat, and settle in
  • Start coding practice by 7:30-8:00pm, which will last for 2-3 hours
  • Focus mainly on hands-on-coding (HTML, CSS, JavaScript)
  • Use tutorials only when stuck
  • End the day with focused practice before sleeping

Days on Duty (Night Shift)

  • Wake up around 5:30-6:00am
  • Spend 2 morning hours learning and practicing coding
  • Focus on building and solving tasks instead of watching videos
  • Rest and prepare for work between 3:30-4:30pm
  • Go to work by 5:00pm with my laptop
  • During quiet hours at work (11pm-12pm), continue coding practice

Days Off Duty

  • Wake and start coding practice in the morning
  • Have Longer, focused sessions for learning and building projects
  • practice again in the evening for reinforcement
  • Work on improving problem-solving skills through real tasks
  • Balance coding with proper rest to avoid burnout
  • Focus on building consistency and discipline
  • Use the day to make real progress on projects
